What is DOM?

DOM (Document Object Model) is a programming interface for HTML and XML documents. It represents the webpage as a tree of objects, allowing JavaScript to access and modify the content, structure, and styles dynamically

What is React?

React is a free and open-source JavaScript library developed by Facebook (Meta) for building fast, interactive, and reusable user interfaces, especially Single Page Applications (SPAs)

What are Components?

A Component is a reusable, independent piece of UI in React. Components help divide the application into smaller, manageable parts. There are two main types Functional Components (recommended) Class Components (older approach)

What are Functions?

A Function is a block of reusable code that performs a specific task. Functions execute only when they are called.
